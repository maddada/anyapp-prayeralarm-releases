# Prayer Alarm

<img src="icon.png" alt="Prayer Alarm" width="96" height="96">

An Android app made with Kiwimake.

No version is published yet.

## Install

1. On your Android phone, open [prayeralarm.apk](https://github.com/maddada/anyapp-prayeralarm-releases/releases/latest/download/prayeralarm.apk).
2. Android asks you to allow installing apps from your browser: allow it, then tap Install.
3. From then on the app tells you when a new version is out. Tap the notification to update.
